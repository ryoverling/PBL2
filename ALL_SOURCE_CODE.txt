# MoneyManager - PBL2 (Qt GUI)

Ứng dụng desktop quản lý chi tiêu cá nhân bằng **C++17 + Qt 6 Widgets**.

Đây là phiên bản đã nối **GUI + core OOP + LinkedList + file local**.

## Chức năng

- Đăng nhập local.
- Dashboard: tổng tài sản, thu/chi tháng, ngân sách, biểu đồ và giao dịch gần đây.
- Quản lý giao dịch Income / Expense.
- Ngày giờ giao dịch tự lấy từ thời gian thật của máy.
- Quản lý nhiều ví.
- Quản lý danh mục.
- Ngân sách theo tuần / tháng / năm / tùy chọn.
- Thống kê theo thời gian.
- Biểu đồ donut chi tiêu theo danh mục.
- Biểu đồ cột 6 tháng gần nhất.
- Lưu dữ liệu bằng file cục bộ.
- `LinkedList<T>` tự cài.
- `Transaction` abstract; `Income`, `Expense` kế thừa.

## Tài khoản mặc định

Lần đầu chạy:

```text
Username: admin
Password: 123456
```

## Kiến trúc

```text
MoneyManager/
├── model/       # Entity OOP
├── manager/     # Nghiệp vụ / quản lý danh sách
├── structure/   # Node<T>, LinkedList<T>
├── storage/     # FileManager
├── utils/       # DateUtils
├── ui/          # Qt Widgets GUI
├── data/        # file runtime
├── main.cpp
└── CMakeLists.txt
```

## Yêu cầu

- C++17
- CMake 3.16+
- Qt 6 có module Widgets
- Compiler phải khớp với Qt kit:
  - Qt MinGW -> dùng MinGW tương ứng
  - Qt MSVC -> dùng Visual Studio compiler tương ứng

## Build bằng Qt Creator

1. Mở `CMakeLists.txt` bằng Qt Creator.
2. Chọn Qt 6 Desktop Kit.
3. Configure Project.
4. Build.
5. Run.

## Build bằng terminal

Nếu CMake tìm được Qt:

```powershell
cmake -S . -B build
cmake --build build
```

Nếu CMake không tìm được Qt:

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:\Qt\6.x.x\mingw_64
cmake --build build
```

Thay đường dẫn bằng Qt trên máy.

## Dữ liệu

Ứng dụng tạo thư mục `data/` **bên cạnh file thực thi**.

Các file runtime:

```text

```

Các file này được `.gitignore` để mỗi máy có dữ liệu riêng.

# Cài Qt để chạy MoneyManager

## Cách dễ nhất: Qt Online Installer + Qt Creator

1. Cài **Qt 6 Desktop**.
2. Chọn một compiler kit:
   - Nếu dùng MinGW: cài đúng MinGW đi kèm Qt.
   - Nếu dùng MSVC: cài Visual Studio C++ workload tương ứng.
3. Mở Qt Creator.
4. Chọn **Open Project** và mở `CMakeLists.txt`.
5. Chọn **Desktop Qt 6.x Kit**.
6. Configure Project -> Build -> Run.

## Dùng VS Code + CMake

Cài extension:

- C/C++
- CMake Tools

Sau đó cần cho CMake biết Qt nằm ở đâu.

Ví dụ Qt MinGW:

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:\Qt\6.8.0\mingw_64
cmake --build build
```

Đổi `6.8.0` và đường dẫn theo máy của bạn.

## Nếu CMake báo không tìm thấy Qt6

Lỗi thường có dạng:

```text
Could not find a package configuration file provided by "Qt6"
```

Điều này nghĩa là CMake chưa biết thư mục Qt.

Dùng:

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH=DUONG_DAN_QT_KIT
```

Ví dụ:

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:\Qt\6.8.0\mingw_64
```

## Dữ liệu

Khi chạy, app tự tạo thư mục `data` cạnh file `.exe`.

Tài khoản mặc định:

```text
admin
123456
```

bool BudgetManager::addBudget(const Budget& budget) {
    if (findById(budget.getId()) != nullptr || budget.getAmount() <= 0) return false;
    budgets.pushBack(budget);
    return true;
}

int BudgetManager::createBudget(double amount, string startDate, string endDate, int categoryId) {
    if (amount <= 0 || startDate > endDate) return -1;
    int id = getNextId();
    budgets.pushBack(Budget(id, amount, startDate, endDate, categoryId));
    return id;
}

bool BudgetManager::deleteBudget(int id) {
    return budgets.removeIf([id](const Budget& b) {
        return b.getId() == id;
    });
}

bool BudgetManager::updateBudgetAmount(int id, double amount) {
    Budget* budget = findById(id);
    if (budget == nullptr || amount <= 0) return false;
    budget->setAmount(amount);
    return true;
}

Budget* BudgetManager::findById(int id) {
    return budgets.findIf([id](const Budget& b) {
        return b.getId() == id;
    });
}

const Budget* BudgetManager::findById(int id) const {
    return budgets.findIf([id](const Budget& b) {
        return b.getId() == id;
    });
}

double BudgetManager::calculateSpent(const Budget& budget, const TransactionManager& transactionManager) const {
    double spent = 0;
    transactionManager.getTransactions().forEach([&](Transaction* const& t) {
        if (t == nullptr || t->getType() != TransactionType::EXPENSE) return;
        if (!DateUtils::isDateInRange(t->getDateTime(), budget.getStartDate(), budget.getEndDate())) return;
        if (budget.getCategoryId() != 0 && t->getCategoryId() != budget.getCategoryId()) return;
        spent += t->getAmount();
    });
    return spent;
}

double BudgetManager::calculateRemaining(const Budget& budget, const TransactionManager& transactionManager) const {
    return budget.getAmount() - calculateSpent(budget, transactionManager);
}

bool BudgetManager::isOverBudget(const Budget& budget, const TransactionManager& transactionManager) const {
    return calculateSpent(budget, transactionManager) > budget.getAmount();
}

bool BudgetManager::hasCategoryBudget(int categoryId) const {
    bool found = false;
    budgets.forEach([&](const Budget& b) {
        if (b.getCategoryId() == categoryId) found = true;
    });
    return found;
}

int BudgetManager::getNextId() const {
    int maxId = 0;
    budgets.forEach([&](const Budget& b) {
        if (b.getId() > maxId) maxId = b.getId();
    });
    return maxId + 1;
}

void BudgetManager::clear() {
    budgets.clear();
}

LinkedList<Budget>& BudgetManager::getBudgets() {
    return budgets;
}

const LinkedList<Budget>& BudgetManager::getBudgets() const {
    return budgets;
}

#include "transaction_manager.h"
#include "../utils/date_utils.h"

TransactionManager::~TransactionManager() {
    clear();
}

bool TransactionManager::validateTransaction(const Transaction* transaction,
                                               const WalletManager& walletManager,
                                               const CategoryManager& categoryManager) const {
    if (transaction == nullptr || transaction->getAmount() <= 0) return false;

    const Wallet* wallet = walletManager.findById(transaction->getWalletId());
    const Category* category = categoryManager.findById(transaction->getCategoryId());
    if (wallet == nullptr || category == nullptr) return false;

    if (transaction->getType() == TransactionType::INCOME &&
        category->getType() != CategoryType::INCOME) return false;

    if (transaction->getType() == TransactionType::EXPENSE &&
        category->getType() != CategoryType::EXPENSE) return false;

    return true;
}

bool TransactionManager::applyWalletEffect(const Transaction* transaction,
                                            WalletManager& walletManager,
                                            bool reverse) {
    if (transaction == nullptr) return false;
    Wallet* wallet = walletManager.findById(transaction->getWalletId());
    if (wallet == nullptr) return false;

    double amount = transaction->getAmount();

    if (!reverse) {
        if (transaction->getType() == TransactionType::INCOME) {
            return wallet->deposit(amount);
        }
        return wallet->withdraw(amount);
    }

    // Hoan tac giao dich cu.
    if (transaction->getType() == TransactionType::INCOME) {
        return wallet->withdraw(amount);
    }
    return wallet->deposit(amount);
}

bool TransactionManager::addTransaction(Transaction* transaction,
                                        WalletManager& walletManager,
                                        const CategoryManager& categoryManager,
                                        bool applyWallet) {
    if (transaction == nullptr) return false;
    if (findById(transaction->getId()) != nullptr) return false;
    if (!validateTransaction(transaction, walletManager, categoryManager)) return false;

    if (applyWallet && !applyWalletEffect(transaction, walletManager, false)) {
        return false;
    }

    transactions.pushBack(transaction);
    return true;
}

bool TransactionManager::addLoadedTransaction(Transaction* transaction) {
    if (transaction == nullptr || findById(transaction->getId()) != nullptr) return false;
    transactions.pushBack(transaction);
    return true;
}

bool TransactionManager::deleteTransaction(int id, WalletManager& walletManager) {
    Transaction* transaction = findById(id);
    if (transaction == nullptr) return false;

    if (!applyWalletEffect(transaction, walletManager, true)) return false;

    Transaction* pointerToDelete = transaction;
    bool removed = transactions.removeIf([id](Transaction* const& t) {
        return t != nullptr && t->getId() == id;
    });

    if (removed) {
        delete pointerToDelete;
        return true;
    }
    return false;
}

bool TransactionManager::updateTransaction(int id,
                                           Transaction* replacement,
                                           WalletManager& walletManager,
                                           const CategoryManager& categoryManager) {
    Transaction* oldTransaction = findById(id);
    if (oldTransaction == nullptr || replacement == nullptr) return false;
    if (replacement->getId() != id) return false;
    if (!validateTransaction(replacement, walletManager, categoryManager)) return false;

    if (!applyWalletEffect(oldTransaction, walletManager, true)) return false;

    if (!applyWalletEffect(replacement, walletManager, false)) {
        applyWalletEffect(oldTransaction, walletManager, false);
        return false;
    }

    Transaction* oldPointer = oldTransaction;
    bool removed = transactions.removeIf([id](Transaction* const& t) {
        return t != nullptr && t->getId() == id;
    });

    if (!removed) {
        applyWalletEffect(replacement, walletManager, true);
        applyWalletEffect(oldTransaction, walletManager, false);
        return false;
    }

    delete oldPointer;
    transactions.pushBack(replacement);
    return true;
}

Transaction* TransactionManager::findById(int id) {
    Transaction** result = transactions.findIf([id](Transaction* const& t) {
        return t != nullptr && t->getId() == id;
    });
    return result == nullptr ? nullptr : *result;
}

const Transaction* TransactionManager::findById(int id) const {
    Transaction* const* result = transactions.findIf([id](Transaction* const& t) {
        return t != nullptr && t->getId() == id;
    });
    return result == nullptr ? nullptr : *result;
}

double TransactionManager::getTotalIncome(string startDate, string endDate) const {
    double total = 0;
    transactions.forEach([&](Transaction* const& t) {
        if (t == nullptr || t->getType() != TransactionType::INCOME) return;
        if (!startDate.empty() && !endDate.empty() &&
            !DateUtils::isDateInRange(t->getDateTime(), startDate, endDate)) return;
        total += t->getAmount();
    });
    return total;
}

double TransactionManager::getTotalExpense(string startDate, string endDate) const {
    double total = 0;
    transactions.forEach([&](Transaction* const& t) {
        if (t == nullptr || t->getType() != TransactionType::EXPENSE) return;
        if (!startDate.empty() && !endDate.empty() &&
            !DateUtils::isDateInRange(t->getDateTime(), startDate, endDate)) return;
        total += t->getAmount();
    });
    return total;
}

bool TransactionManager::hasWalletTransactions(int walletId) const {
    bool found = false;
    transactions.forEach([&](Transaction* const& t) {
        if (t != nullptr && t->getWalletId() == walletId) found = true;
    });
    return found;
}

bool TransactionManager::hasCategoryTransactions(int categoryId) const {
    bool found = false;
    transactions.forEach([&](Transaction* const& t) {
        if (t != nullptr && t->getCategoryId() == categoryId) found = true;
    });
    return found;
}

int TransactionManager::getNextId() const {
    int maxId = 0;
    transactions.forEach([&](Transaction* const& t) {
        if (t != nullptr && t->getId() > maxId) maxId = t->getId();
    });
    return maxId + 1;
}

void TransactionManager::clear() {
    transactions.forEach([](Transaction*& t) {
        delete t;
        t = nullptr;
    });
    transactions.clear();
}

LinkedList<Transaction*>& TransactionManager::getTransactions() {
    return transactions;
}

const LinkedList<Transaction*>& TransactionManager::getTransactions() const {
    return transactions;
}

    vector<string> splitLine(const string& line, char delimiter = '|') {
        vector<string> parts;
        string item;
        stringstream ss(line);
        while (getline(ss, item, delimiter)) {
            parts.push_back(item);
        }
        return parts;
    }
}

string FileManager::sanitize(const string& value) {
    string result = value;
    for (char& c : result) {
        if (c == '|' || c == '\n' || c == '\r') c = ' ';
    }
    return result;
}

void FileManager::ensureDataDirectory(const string& directory) {
    filesystem::create_directories(directory);
}

bool FileManager::loadUser(const string& path, User& user) {
    ifstream file(path);
    if (!file) return false;

    string line;
    if (!getline(file, line)) return false;
    vector<string> p = splitLine(line);
    if (p.size() < 3) return false;

    user = User(p[0], p[1], p[2]);
    return true;
}

bool FileManager::saveUser(const string& path, const User& user) {
    ofstream file(path);
    if (!file) return false;
    file << sanitize(user.getUsername()) << '|'
         << sanitize(user.getPassword()) << '|'
         << sanitize(user.getName()) << '\n';
    return true;
}

bool FileManager::loadCategories(const string& path, CategoryManager& manager) {
    ifstream file(path);
    if (!file) return false;
    manager.clear();

    string line;
    while (getline(file, line)) {
        if (line.empty()) continue;
        vector<string> p = splitLine(line);
        if (p.size() < 3) continue;
        try {
            int id = stoi(p[0]);
            manager.addCategory(Category(id, p[1], categoryTypeFromString(p[2])));
        } catch (...) {}
    }
    return true;
}

             << categoryTypeToString(c.getType()) << '\n';
    });
    return true;
}

bool FileManager::loadTransactions(const string& path, TransactionManager& manager) {
    ifstream file(path);
    if (!file) return false;
    manager.clear();

    string line;
    while (getline(file, line)) {
        if (line.empty()) continue;
        vector<string> p = splitLine(line);
        if (p.size() < 7) continue;

        try {
            int id = stoi(p[0]);
            double amount = stod(p[2]);
            int walletId = stoi(p[3]);
            int categoryId = stoi(p[4]);

            Transaction* t = nullptr;
            if (p[1] == "INCOME") {
                t = new Income(id, amount, p[5], p[6], walletId, categoryId);
            } else if (p[1] == "EXPENSE") {
                t = new Expense(id, amount, p[5], p[6], walletId, categoryId);
            }

            if (t != nullptr && !manager.addLoadedTransaction(t)) {
                delete t;
            }
        } catch (...) {}
    }
    return true;
}

#pragma once

#include <cstddef>
#include "node.h"
using namespace std;

template <typename T>
class LinkedList {
private:
    Node<T>* head;
    Node<T>* tail;
    size_t size;

public:
    LinkedList() {
        head = nullptr;
        tail = nullptr;
        size = 0;
    }

    ~LinkedList() {
        clear();
    }

    LinkedList(const LinkedList&) = delete;
    LinkedList& operator=(const LinkedList&) = delete;

    bool isEmpty() const {
        return size == 0;
    }

    size_t getSize() const {
        return size;
    }

    void pushBack(const T& value) {
        Node<T>* node = new Node<T>(value);
        if (tail == nullptr) {
            head = tail = node;
        } else {
            tail->next = node;
            tail = node;
        }
        size++;
    }

    template <typename Predicate>
    bool removeIf(Predicate predicate) {
        Node<T>* current = head;
        Node<T>* previous = nullptr;

        while (current != nullptr) {
            if (predicate(current->data)) {
                if (previous == nullptr) {
                    head = current->next;
                } else {
                    previous->next = current->next;
                }

                if (current == tail) {
                    tail = previous;
                }

                delete current;
                size--;
                return true;
            }

            previous = current;
            current = current->next;
        }
        return false;
    }

    template <typename Predicate>
    T* findIf(Predicate predicate) {
        Node<T>* current = head;
        while (current != nullptr) {
            if (predicate(current->data)) {
                return &current->data;
            }
            current = current->next;
        }
        return nullptr;
    }

    template <typename Predicate>
    const T* findIf(Predicate predicate) const {
        Node<T>* current = head;
        while (current != nullptr) {
            if (predicate(current->data)) {
                return &current->data;
            }
            current = current->next;
        }
        return nullptr;
    }

    template <typename Func>
    void forEach(Func func) {
        Node<T>* current = head;
        while (current != nullptr) {
            func(current->data);
            current = current->next;
        }
    }

    template <typename Func>
    void forEach(Func func) const {
        Node<T>* current = head;
        while (current != nullptr) {
            func(current->data);
            current = current->next;
        }
    }

    void clear() {
        Node<T>* current = head;
        while (current != nullptr) {
            Node<T>* nextNode = current->next;
            delete current;
            current = nextNode;
        }
        head = tail = nullptr;
        size = 0;
    }
};

QString BudgetDialog::startDate() const {
    int mode = periodCombo->currentData().toInt();
    QDate ref = referenceDate->date();

    if (mode == 0) {
        int dayOfWeek = ref.dayOfWeek();
        return ref.addDays(1 - dayOfWeek).toString("yyyy-MM-dd");
    }
    if (mode == 1) {
        return QDate(ref.year(), ref.month(), 1).toString("yyyy-MM-dd");
    }
    if (mode == 2) {
        return QDate(ref.year(), 1, 1).toString("yyyy-MM-dd");
    }
    return customStart->date().toString("yyyy-MM-dd");
}

QString BudgetDialog::endDate() const {
    int mode = periodCombo->currentData().toInt();
    QDate ref = referenceDate->date();

    if (mode == 0) {
        int dayOfWeek = ref.dayOfWeek();
        return ref.addDays(7 - dayOfWeek).toString("yyyy-MM-dd");
    }
    if (mode == 1) {
        return QDate(ref.year(), ref.month(), 1)
            .addMonths(1).addDays(-1)
            .toString("yyyy-MM-dd");
    }
    if (mode == 2) {
        return QDate(ref.year(), 12, 31).toString("yyyy-MM-dd");
    }
    return customEnd->date().toString("yyyy-MM-dd");
}

QString BudgetPage::periodLabel(const std::string& start, const std::string& end) const {
    QDate s = QDate::fromString(QString::fromStdString(start), "yyyy-MM-dd");
    QDate e = QDate::fromString(QString::fromStdString(end), "yyyy-MM-dd");

    if (!s.isValid() || !e.isValid()) return "Tùy chọn";
    if (s.daysTo(e) == 6 && s.dayOfWeek() == 1) return "Tuần";
    if (s.day() == 1 && e == s.addMonths(1).addDays(-1)) return "Tháng";
    if (s.month() == 1 && s.day() == 1 && e.month() == 12 && e.day() == 31 &&
        s.year() == e.year()) return "Năm";
    return "Tùy chọn";
}

void BudgetPage::refresh() {
    table->setRowCount(0);

    budgets->getBudgets().forEach([&](const Budget& budget) {
        double spent = budgets->calculateSpent(budget, *transactions);
        double remaining = budgets->calculateRemaining(budget, *transactions);
        bool over = budgets->isOverBudget(budget, *transactions);

        const Category* category = budget.getCategoryId() == 0
            ? nullptr
            : categories->findById(budget.getCategoryId());

        QString categoryName = budget.getCategoryId() == 0
            ? "Tất cả chi tiêu"
            : (category ? QString::fromStdString(category->getName()) : "Không rõ");

        int row = table->rowCount();
        table->insertRow(row);

        QTableWidgetItem* first = new QTableWidgetItem(categoryName);
        first->setData(Qt::UserRole, budget.getId());

        table->setItem(row, 0, first);
        table->setItem(row, 1, new QTableWidgetItem(
            periodLabel(budget.getStartDate(), budget.getEndDate())
        ));
        table->setItem(row, 2, new QTableWidgetItem(
            UiHelpers::dateDisplay(budget.getStartDate()) + " - " +
            UiHelpers::dateDisplay(budget.getEndDate())
        ));
        table->setItem(row, 3, new QTableWidgetItem(UiHelpers::money(budget.getAmount())));
        table->setItem(row, 4, new QTableWidgetItem(UiHelpers::money(spent)));
        table->setItem(row, 5, new QTableWidgetItem(UiHelpers::money(remaining)));
        table->setItem(row, 6, new QTableWidgetItem(over ? "Vượt ngân sách" : "Trong giới hạn"));

        if (over) {
            table->item(row, 6)->setForeground(QColor("#b42318"));
        }
    });
}

void DonutChartWidget::paintEvent(QPaintEvent*) {
    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing);

    QRectF area = rect().adjusted(16, 16, -16, -16);
    double legendWidth = qMin(180.0, area.width() * 0.42);
    QRectF chartArea(area.left(), area.top(), area.width() - legendWidth - 12, area.height());

    double diameter = qMin(chartArea.width(), chartArea.height()) * 0.82;
    QRectF pieRect(
        chartArea.center().x() - diameter / 2,
        chartArea.center().y() - diameter / 2,
        diameter,
        diameter
    );

    double total = 0;
    for (const auto& slice : slices) {
        if (slice.value > 0) total += slice.value;
    }

    if (total <= 0) {
        painter.setPen(QColor("#8b8e96"));
        painter.drawText(area, Qt::AlignCenter, "Chưa có dữ liệu chi tiêu");
        return;
    }

    int startAngle = 90 * 16;
    for (const auto& slice : slices) {
        if (slice.value <= 0) continue;
        int span = -qRound((slice.value / total) * 360.0 * 16.0);
        painter.setPen(Qt::NoPen);
        painter.setBrush(slice.color);
        painter.drawPie(pieRect, startAngle, span);
        startAngle += span;
    }

    double hole = diameter * 0.54;
    QRectF holeRect(
        pieRect.center().x() - hole / 2,
        pieRect.center().y() - hole / 2,
        hole,
        hole
    );
    painter.setBrush(QColor("#ffffff"));
    painter.setPen(Qt::NoPen);
    painter.drawEllipse(holeRect);

    painter.setPen(QColor("#202124"));
    QFont totalFont = painter.font();
    totalFont.setPointSize(12);
    totalFont.setBold(true);
    painter.setFont(totalFont);
    painter.drawText(holeRect, Qt::AlignCenter, "Chi tiêu");

    double x = area.right() - legendWidth;
    double y = area.top() + 8;
    QFont legendFont = painter.font();
    legendFont.setPointSize(9);
    legendFont.setBold(false);
    painter.setFont(legendFont);

    int shown = 0;
    for (const auto& slice : slices) {
        if (slice.value <= 0 || shown >= 7) continue;

        painter.setBrush(slice.color);
        painter.setPen(Qt::NoPen);
        painter.drawRoundedRect(QRectF(x, y + 4, 10, 10), 2, 2);

        painter.setPen(QColor("#33353a"));
        QString text = QString("%1  %2%")
            .arg(slice.label)
            .arg(QString::number(slice.value * 100.0 / total, 'f', 0));
        painter.drawText(QRectF(x + 18, y, legendWidth - 18, 20),
                         Qt::AlignLeft | Qt::AlignVCenter, text);

        y += 28;
        shown++;
    }
}

    values = newValues;
    update();
}

void BarChartWidget::paintEvent(QPaintEvent*) {
    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing);

    QRectF area = rect().adjusted(24, 20, -18, -36);
    if (values.isEmpty()) {
        painter.setPen(QColor("#8b8e96"));
        painter.drawText(area, Qt::AlignCenter, "Chưa có dữ liệu");
        return;
    }

    double maxValue = 0;
    for (double value : values) maxValue = qMax(maxValue, value);
    if (maxValue <= 0) maxValue = 1;

    painter.setPen(QPen(QColor("#e6e8ed"), 1));
    for (int i = 0; i <= 4; ++i) {
        double y = area.bottom() - area.height() * i / 4.0;
        painter.drawLine(QPointF(area.left(), y), QPointF(area.right(), y));
    }

    int n = values.size();
    double slot = area.width() / qMax(1, n);
    double barWidth = qMin(44.0, slot * 0.56);

    for (int i = 0; i < n; ++i) {
        double ratio = qBound(0.0, values[i] / maxValue, 1.0);
        double h = area.height() * ratio;
        double x = area.left() + slot * i + (slot - barWidth) / 2;
        QRectF bar(x, area.bottom() - h, barWidth, h);

        painter.setBrush(QColor("#6c4ed9"));
        painter.setPen(Qt::NoPen);
        painter.drawRoundedRect(bar, 6, 6);

        painter.setPen(QColor("#6f727a"));
        QString label = i < labels.size() ? labels[i] : QString::number(i + 1);
        painter.drawText(
            QRectF(area.left() + slot * i, area.bottom() + 8, slot, 22),
            Qt::AlignHCenter | Qt::AlignTop,
            label
        );
    }
}

void DashboardPage::refresh() {
    QDate now = QDate::currentDate();
    QDate first(now.year(), now.month(), 1);
    QDate last = first.addMonths(1).addDays(-1);

    string monthStart = first.toString("yyyy-MM-dd").toStdString();
    string monthEnd = last.toString("yyyy-MM-dd").toStdString();

    double income = transactions->getTotalIncome(monthStart, monthEnd);
    double expense = transactions->getTotalExpense(monthStart, monthEnd);

    totalBalanceLabel->setText(UiHelpers::money(wallets->getTotalBalance()));
    incomeLabel->setText(UiHelpers::money(income));
    expenseLabel->setText(UiHelpers::money(expense));
    differenceLabel->setText(UiHelpers::money(income - expense));

    std::map<int, double> categoryTotals;
    transactions->getTransactions().forEach([&](Transaction* const& t) {
        if (t == nullptr || t->getType() != TransactionType::EXPENSE) return;
        QString date = QString::fromStdString(t->getDateTime()).left(10);
        if (date < first.toString("yyyy-MM-dd") || date > last.toString("yyyy-MM-dd")) return;
        categoryTotals[t->getCategoryId()] += t->getAmount();
    });

    QVector<QColor> palette = {
        QColor("#6c4ed9"), QColor("#f09a58"), QColor("#51a8a2"),
        QColor("#d56486"), QColor("#5c85d6"), QColor("#d1a83d"),
        QColor("#8d6ab8"), QColor("#7c9a50")
    };

    QVector<ChartSlice> slices;
    int colorIndex = 0;
    for (const auto& [categoryId, value] : categoryTotals) {
        const Category* category = categories->findById(categoryId);
        slices.push_back({
            category ? QString::fromStdString(category->getName()) : "Không rõ",
            value,
            palette[colorIndex % palette.size()]
        });
        colorIndex++;
    }
    donutChart->setData(slices);

    string today = now.toString("yyyy-MM-dd").toStdString();
    double totalBudget = 0;
    double totalSpent = 0;
    int activeCount = 0;

    budgets->getBudgets().forEach([&](const Budget& budget) {
        if (today < budget.getStartDate() || today > budget.getEndDate()) return;
        totalBudget += budget.getAmount();
        totalSpent += budgets->calculateSpent(budget, *transactions);
        activeCount++;
    });

    if (activeCount == 0 || totalBudget <= 0) {
        budgetDetailLabel->setText("Chưa có ngân sách đang áp dụng.");
        budgetProgress->setValue(0);
        budgetProgress->setFormat("0%");
    } else {
        int percent = qRound(totalSpent * 100.0 / totalBudget);
        budgetDetailLabel->setText(
            QString("%1 ngân sách • Đã chi %2 / %3")
                .arg(activeCount)
                .arg(UiHelpers::money(totalSpent))
                .arg(UiHelpers::money(totalBudget))
        );
        budgetProgress->setValue(qMin(percent, 100));
        budgetProgress->setFormat(QString::number(percent) + "%");
    }

    std::vector<const Transaction*> items;
    transactions->getTransactions().forEach([&](Transaction* const& t) {
        if (t != nullptr) items.push_back(t);
    });

    std::sort(items.begin(), items.end(), [](const Transaction* a, const Transaction* b) {
        return a->getDateTime() > b->getDateTime();
    });

    recentTable->setRowCount(0);
    int limit = qMin(6, static_cast<int>(items.size()));

    for (int i = 0; i < limit; ++i) {
        const Transaction* t = items[i];
        const Category* category = categories->findById(t->getCategoryId());
        const Wallet* wallet = wallets->findById(t->getWalletId());

        int row = recentTable->rowCount();
        recentTable->insertRow(row);

        recentTable->setItem(row, 0, new QTableWidgetItem(
            UiHelpers::dateTimeDisplay(t->getDateTime())
        ));
        recentTable->setItem(row, 1, new QTableWidgetItem(
            t->getType() == TransactionType::INCOME ? "Thu nhập" : "Chi tiêu"
        ));
        recentTable->setItem(row, 2, new QTableWidgetItem(
            category ? QString::fromStdString(category->getName()) : "Không rõ"
        ));
        recentTable->setItem(row, 3, new QTableWidgetItem(
            wallet ? QString::fromStdString(wallet->getName()) : "Không rõ"
        ));
        recentTable->setItem(row, 4, new QTableWidgetItem(
            UiHelpers::money(t->getSignedAmount())
        ));
    }
}

void LoginWindow::ensureDefaultUser() {
    User user;
    if (!FileManager::loadUser(DataPaths::userFile(), user)) {
        user = User("admin", "123456", "Người dùng");
        FileManager::saveUser(DataPaths::userFile(), user);
    }
}

void LoginWindow::handleLogin() {
    User user;
    if (!FileManager::loadUser(DataPaths::userFile(), user)) {
        messageLabel->setText("Không thể đọc dữ liệu người dùng.");
        return;
    }

    string username = usernameInput->text().trimmed().toStdString();
    string password = passwordInput->text().toStdString();

    if (!user.login(username, password)) {
        messageLabel->setText("Tên đăng nhập hoặc mật khẩu không đúng.");
        return;
    }

    messageLabel->clear();

    MainWindow* mainWindow = new MainWindow(
        QString::fromStdString(user.getName()),
        [this]() {
            usernameInput->clear();
            passwordInput->clear();
            messageLabel->clear();
            this->show();
            this->raise();
            this->activateWindow();
        }
    );

    mainWindow->setAttribute(Qt::WA_DeleteOnClose);
    mainWindow->show();
    hide();
}

QString StatisticsPage::startDate() const {
    QDate ref = referenceDate->date();
    int mode = periodCombo->currentData().toInt();

    if (mode == 0) return ref.addDays(1 - ref.dayOfWeek()).toString("yyyy-MM-dd");
    if (mode == 1) return QDate(ref.year(), ref.month(), 1).toString("yyyy-MM-dd");
    if (mode == 2) return QDate(ref.year(), 1, 1).toString("yyyy-MM-dd");
    return customStart->date().toString("yyyy-MM-dd");
}

QString StatisticsPage::endDate() const {
    QDate ref = referenceDate->date();
    int mode = periodCombo->currentData().toInt();

    if (mode == 0) return ref.addDays(7 - ref.dayOfWeek()).toString("yyyy-MM-dd");
    if (mode == 1) {
        return QDate(ref.year(), ref.month(), 1)
            .addMonths(1).addDays(-1)
            .toString("yyyy-MM-dd");
    }
    if (mode == 2) return QDate(ref.year(), 12, 31).toString("yyyy-MM-dd");
    return customEnd->date().toString("yyyy-MM-dd");
}

void StatisticsPage::updatePeriodUi() {
    bool custom = periodCombo->currentData().toInt() == 3;
    referenceDate->setVisible(!custom);
    customStart->setVisible(custom);
    customEnd->setVisible(custom);
}

void StatisticsPage::refresh() {
    string start = startDate().toStdString();
    string end = endDate().toStdString();

    double income = transactions->getTotalIncome(start, end);
    double expense = transactions->getTotalExpense(start, end);

    incomeLabel->setText(UiHelpers::money(income));
    expenseLabel->setText(UiHelpers::money(expense));
    differenceLabel->setText(UiHelpers::money(income - expense));

    std::map<int, double> totals;
    transactions->getTransactions().forEach([&](Transaction* const& t) {
        if (t == nullptr || t->getType() != TransactionType::EXPENSE) return;
        QString date = QString::fromStdString(t->getDateTime()).left(10);
        if (date < QString::fromStdString(start) || date > QString::fromStdString(end)) return;
        totals[t->getCategoryId()] += t->getAmount();
    });

    QVector<QColor> palette = {
        QColor("#6c4ed9"), QColor("#f09a58"), QColor("#51a8a2"),
        QColor("#d56486"), QColor("#5c85d6"), QColor("#d1a83d"),
        QColor("#8d6ab8"), QColor("#7c9a50")
    };

    QVector<ChartSlice> slices;
    int colorIndex = 0;
    for (const auto& [categoryId, value] : totals) {
        const Category* category = categories->findById(categoryId);
        slices.push_back({
            category ? QString::fromStdString(category->getName()) : "Không rõ",
            value,
            palette[colorIndex % palette.size()]
        });
        colorIndex++;
    }
    donutChart->setData(slices);

    QStringList monthLabels;
    QVector<double> monthValues;
    QDate now = QDate::currentDate();

    for (int offset = 5; offset >= 0; --offset) {
        QDate month = QDate(now.year(), now.month(), 1).addMonths(-offset);
        QDate last = month.addMonths(1).addDays(-1);

        string monthStart = month.toString("yyyy-MM-dd").toStdString();
        string monthEnd = last.toString("yyyy-MM-dd").toStdString();

        monthLabels << month.toString("MM/yy");
        monthValues << transactions->getTotalExpense(monthStart, monthEnd);
    }

    barChart->setData(monthLabels, monthValues);
}

void TransactionDialog::populateWallets() {
    int previous = walletCombo->currentData().toInt();
    walletCombo->clear();

    wallets->getWallets().forEach([&](const Wallet& wallet) {
        walletCombo->addItem(
            QString::fromStdString(wallet.getName()),
            wallet.getId()
        );
    });

    int index = walletCombo->findData(previous);
    if (index >= 0) walletCombo->setCurrentIndex(index);
}

void TransactionDialog::populateCategories() {
    int previous = categoryCombo->currentData().toInt();
    categoryCombo->clear();

    TransactionType type = static_cast<TransactionType>(typeCombo->currentData().toInt());
    CategoryType wanted = type == TransactionType::INCOME
        ? CategoryType::INCOME
        : CategoryType::EXPENSE;

    categories->getCategories().forEach([&](const Category& category) {
        if (category.getType() != wanted) return;
        categoryCombo->addItem(
            QString::fromStdString(category.getName()),
            category.getId()
        );
    });

    int index = categoryCombo->findData(previous);
    if (index >= 0) categoryCombo->setCurrentIndex(index);
}

void TransactionDialog::validateAndAccept() {
    if (walletCombo->currentIndex() < 0) {
        QMessageBox::warning(this, "Thiếu ví", "Vui lòng tạo ít nhất một ví.");
        return;
    }

    if (categoryCombo->currentIndex() < 0) {
        QMessageBox::warning(this, "Thiếu danh mục", "Không có danh mục phù hợp.");
        return;
    }

    QString categoryName = categoryCombo->currentText().toLower();
    if ((categoryName.contains("khác") || categoryName.contains("khac")) &&
        noteInput->toPlainText().trimmed().isEmpty()) {
        QMessageBox::warning(
            this,
            "Cần ghi chú",
            "Với danh mục Khác, vui lòng ghi rõ nội dung giao dịch."
        );
        return;
    }

    accept();
}

Transaction* TransactionDialog::createTransaction(int id) const {
    TransactionType type = static_cast<TransactionType>(typeCombo->currentData().toInt());
    double amount = amountInput->value();
    int walletId = walletCombo->currentData().toInt();
    int categoryId = categoryCombo->currentData().toInt();
    string note = noteInput->toPlainText().trimmed().toStdString();

    string dateTime = existing
        ? existing->getDateTime()
        : DateUtils::getCurrentDateTime();

    if (type == TransactionType::INCOME) {
        return new Income(id, amount, dateTime, note, walletId, categoryId);
    }

    return new Expense(id, amount, dateTime, note, walletId, categoryId);
}

void TransactionPage::rebuildFilters() {
    int oldWallet = walletFilter->currentData().toInt();
    int oldCategory = categoryFilter->currentData().toInt();

    walletFilter->blockSignals(true);
    categoryFilter->blockSignals(true);

    walletFilter->clear();
    walletFilter->addItem("Tất cả ví", 0);
    wallets->getWallets().forEach([&](const Wallet& wallet) {
        walletFilter->addItem(QString::fromStdString(wallet.getName()), wallet.getId());
    });

    categoryFilter->clear();
    categoryFilter->addItem("Tất cả danh mục", 0);
    categories->getCategories().forEach([&](const Category& category) {
        categoryFilter->addItem(QString::fromStdString(category.getName()), category.getId());
    });

    int walletIndex = walletFilter->findData(oldWallet);
    if (walletIndex >= 0) walletFilter->setCurrentIndex(walletIndex);

    int categoryIndex = categoryFilter->findData(oldCategory);
    if (categoryIndex >= 0) categoryFilter->setCurrentIndex(categoryIndex);

    walletFilter->blockSignals(false);
    categoryFilter->blockSignals(false);
}

void TransactionPage::updatePeriodControls() {
    bool custom = periodFilter->currentData().toInt() == 2;
    fromDate->setVisible(custom);
    toDate->setVisible(custom);
}

bool TransactionPage::passesDateFilter(const std::string& dateTime) const {
    int mode = periodFilter->currentData().toInt();
    if (mode == 0) return true;

    QDate date = QDate::fromString(
        QString::fromStdString(dateTime).left(10),
        "yyyy-MM-dd"
    );
    if (!date.isValid()) return false;

    if (mode == 1) {
        QDate now = QDate::currentDate();
        return date.year() == now.year() && date.month() == now.month();
    }

    return date >= fromDate->date() && date <= toDate->date();
}

void TransactionPage::refresh() {
    rebuildFilters();
    table->setRowCount(0);

    QString query = searchInput->text().trimmed().toLower();
    int type = typeFilter->currentData().toInt();
    int walletId = walletFilter->currentData().toInt();
    int categoryId = categoryFilter->currentData().toInt();

    std::vector<const Transaction*> items;
    transactions->getTransactions().forEach([&](Transaction* const& t) {
        if (t != nullptr) items.push_back(t);
    });

    std::sort(items.begin(), items.end(), [](const Transaction* a, const Transaction* b) {
        return a->getDateTime() > b->getDateTime();
    });

    for (const Transaction* t : items) {
        if (type != -1 && static_cast<int>(t->getType()) != type) continue;
        if (walletId != 0 && t->getWalletId() != walletId) continue;
        if (categoryId != 0 && t->getCategoryId() != categoryId) continue;
        if (!passesDateFilter(t->getDateTime())) continue;

        const Category* category = categories->findById(t->getCategoryId());
        const Wallet* wallet = wallets->findById(t->getWalletId());

        QString categoryName = category
            ? QString::fromStdString(category->getName())
            : "Không rõ";
        QString walletName = wallet
            ? QString::fromStdString(wallet->getName())
            : "Không rõ";

        QString searchable = (
            QString::fromStdString(t->getNote()) + " " +
            categoryName + " " + walletName
        ).toLower();

        if (!query.isEmpty() && !searchable.contains(query)) continue;

        int row = table->rowCount();
        table->insertRow(row);

        QTableWidgetItem* timeItem = new QTableWidgetItem(
            UiHelpers::dateTimeDisplay(t->getDateTime())
        );
        timeItem->setData(Qt::UserRole, t->getId());

        table->setItem(row, 0, timeItem);
        table->setItem(row, 1, new QTableWidgetItem(
            t->getType() == TransactionType::INCOME ? "Thu nhập" : "Chi tiêu"
        ));
        table->setItem(row, 2, new QTableWidgetItem(categoryName));
        table->setItem(row, 3, new QTableWidgetItem(walletName));
        table->setItem(row, 4, new QTableWidgetItem(QString::fromStdString(t->getNote())));
        table->setItem(row, 5, new QTableWidgetItem(UiHelpers::money(t->getSignedAmount())));
    }
}

void TransactionPage::addTransaction() {
    if (wallets->getWallets().isEmpty()) {
        QMessageBox::warning(this, "Chưa có ví", "Hãy tạo ví trước khi thêm giao dịch.");
        return;
    }

    TransactionDialog dialog(wallets, categories, nullptr, this);
    if (dialog.exec() != QDialog::Accepted) return;

    int id = transactions->getNextId();
    Transaction* transaction = dialog.createTransaction(id);

    if (!transactions->addTransaction(transaction, *wallets, *categories)) {
        delete transaction;
        QMessageBox::warning(this, "Không thể thêm", "Dữ liệu giao dịch không hợp lệ.");
        return;
    }

    if (onChanged) onChanged();
}

void TransactionPage::editTransaction() {
    int id = selectedId();
    Transaction* oldTransaction = transactions->findById(id);
    if (oldTransaction == nullptr) {
        QMessageBox::information(this, "Giao dịch", "Vui lòng chọn một giao dịch.");
        return;
    }

    TransactionDialog dialog(wallets, categories, oldTransaction, this);
    if (dialog.exec() != QDialog::Accepted) return;

    Transaction* replacement = dialog.createTransaction(id);

    if (!transactions->updateTransaction(
            id, replacement, *wallets, *categories
        )) {
        delete replacement;
        QMessageBox::warning(this, "Không thể sửa", "Không thể cập nhật giao dịch.");
        return;
    }

    if (onChanged) onChanged();
}

void TransactionPage::deleteTransaction() {
    int id = selectedId();
    const Transaction* transaction = transactions->findById(id);
    if (transaction == nullptr) {
        QMessageBox::information(this, "Giao dịch", "Vui lòng chọn một giao dịch.");
        return;
    }

    if (QMessageBox::question(
            this,
            "Xóa giao dịch",
            "Bạn có chắc muốn xóa giao dịch đã chọn?"
        ) != QMessageBox::Yes) {
        return;
    }

    if (!transactions->deleteTransaction(id, *wallets)) {
        QMessageBox::warning(this, "Lỗi", "Không thể xóa giao dịch.");
        return;
    }

    if (onChanged) onChanged();
}

#include "date_utils.h"

#include <ctime>
#include <iomanip>
#include <sstream>

namespace {
    bool isLeapYear(int year) {
        return (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
    }

    int daysInMonth(int year, int month) {
        static int days[] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
        if (month == 2 && isLeapYear(year)) return 29;
        if (month < 1 || month > 12) return 0;
        return days[month];
    }

    bool parseDate(const string& date, int& year, int& month, int& day) {
        if (date.size() != 10 || date[4] != '-' || date[7] != '-') return false;
        try {
            year = stoi(date.substr(0,4));
            month = stoi(date.substr(5,2));
            day = stoi(date.substr(8,2));
        } catch (...) {
            return false;
        }
        if (year < 1900 || month < 1 || month > 12) return false;
        if (day < 1 || day > daysInMonth(year, month)) return false;
        return true;
    }
}

string DateUtils::getCurrentDateTime() {
    time_t now = time(nullptr);
    tm localTime{};
#ifdef _WIN32
    localtime_s(&localTime, &now);
#else
    localtime_r(&now, &localTime);
#endif
    ostringstream out;
    out << put_time(&localTime, "%Y-%m-%d %H:%M:%S");
    return out.str();
}

string DateUtils::getCurrentDate() {
    return getCurrentDateTime().substr(0, 10);
}

bool DateUtils::isValidDate(const string& date) {
    int year, month, day;
    return parseDate(date, year, month, day);
}

string DateUtils::addDays(const string& date, int days) {
    int year, month, day;
    if (!parseDate(date, year, month, day)) return "";

    tm value{};
    value.tm_year = year - 1900;
    value.tm_mon = month - 1;
    value.tm_mday = day + days;
    value.tm_hour = 12;

    time_t t = mktime(&value);
    if (t == -1) return "";

    tm result{};
#ifdef _WIN32
    localtime_s(&result, &t);
#else
    localtime_r(&t, &result);
#endif
    ostringstream out;
    out << put_time(&result, "%Y-%m-%d");
    return out.str();
}

void DateUtils::getMonthRange(int year, int month, string& startDate, string& endDate) {
    ostringstream start, end;
    start << setw(4) << setfill('0') << year << "-"
          << setw(2) << month << "-01";
    end << setw(4) << setfill('0') << year << "-"
        << setw(2) << month << "-"
        << setw(2) << daysInMonth(year, month);
    startDate = start.str();
    endDate = end.str();
}

void DateUtils::getYearRange(int year, string& startDate, string& endDate) {
    startDate = to_string(year) + "-01-01";
    endDate = to_string(year) + "-12-31";
}

bool DateUtils::isDateInRange(const string& dateTime, const string& startDate, const string& endDate) {
    if (dateTime.size() < 10) return false;
    string date = dateTime.substr(0,10);
    return date >= startDate && date <= endDate;
}
